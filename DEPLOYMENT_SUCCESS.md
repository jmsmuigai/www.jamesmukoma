1. **Purchase Domain** (if not already done):

2. **Configure DNS Records**:
   ```
   Type: CNAME
   Name: www
   Value: jmsmuigai.github.io
   
   Type: A
   Name: @
   Value: 185.199.108.153
   Value: 185.199.109.153
   Value: 185.199.110.153
   Value: 185.199.111.153
   ```

3. **Update GitHub Pages Settings**:
   - Go to: https://github.com/jmsmuigai/www.jamesmukoma/settings/pages
   - Add custom domain: `www.jamesmukoma.com`
   - Enable "Enforce HTTPS"

4. **Update Website URLs** (after domain setup):
